This is an ASCII game that Andy Jiang and Finley Ye made
In GOOBERS, there are various types of enemies:"The teleporter, the spawner and the slow enemy spawned by the spawner. 
It contains a simple lore, when the game started type lore to get access to the story and the basic introduction of all the enemies and abilities
The theme of the game is" I'm just a little guy", in the game, it is displayed as the player where it tries to avoid all the enemies and get to the point"O" which is also the exit of the maze.
We also used the abilities, enemies, lore and text to match this jame gam theme.
We tried to match the theme color by adding the colors to make the game more appealing.
GOOBERS uses various theme colors to represent the different roles in the game.
We put in most of our time in developing the enemies algorithm since we felt like it was more important for the experience.
